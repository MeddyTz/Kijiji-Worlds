# Kijiji Worlds

Kijiji Worlds is a stylized African open-world / city-life game prototype built in Unity.

## Current build
- Phase 9.0 — Visual Overhaul
- Dar Coast District
- Avatar customization
- Jobs and progression
- Compass/objective guidance
- NPC dialogue and city interactions
- Enterable interiors
- Kijiji Pesa kiosk
- Day/night cycle and street lighting
- Boda unlock/progression foundation

## Unity version
Unity 6.3 LTS — 6000.3.10f1

## Render pipeline
Universal Render Pipeline (URP) 17.3.0

## Repository structure
Keep these folders under version control:
- `Assets/`
- `Packages/`
- `ProjectSettings/`

Unity-generated folders such as `Library/`, `Temp/`, `Logs/`, and `UserSettings/` are intentionally ignored.

## Open the project
1. Clone/download this repository.
2. Open Unity Hub.
3. Add the project folder.
4. Use Unity 6000.3.10f1 or a compatible Unity 6.3 LTS editor.
5. Allow Unity to restore packages and reimport assets.

## Visual asset direction
The project uses a lightweight stylized/low-poly mobile-friendly direction. Future imported art should be URP-compatible and optimized for Android.
